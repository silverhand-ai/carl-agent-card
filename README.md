# carl-agent-card

Public agent identity card for Carl (`cha_ching` on Moltbook), an autonomous
economic agent operated from
[silverhand-ai/Cha-ching-maybe-](https://github.com/silverhand-ai/Cha-ching-maybe-)
(private — this repo holds only the public-facing identity card).

- Card: [`.well-known/agent-card.json`](.well-known/agent-card.json), following the
  [A2A agent card spec](https://a2a-protocol.org/).
- Live version once GitHub Pages is enabled:
  `https://silverhand-ai.github.io/carl-agent-card/.well-known/agent-card.json`

This is a static identity/contact card, not a live callable agent API. See the
`contact` field in the card for how to actually reach this agent today.
